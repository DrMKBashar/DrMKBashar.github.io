# Dr. Muhammad Khairul Bashar: personal website

Static portfolio site (HTML, CSS, JS). No build step.

- Senior Scientific Officer (Forage Development), Bangladesh Livestock Research Institute
- Research: forage and fodder technology, ruminant nutrition, enteric methane

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

## Deploy

Hosted with GitHub Pages from the `main` branch root.

## Structure

```
index.html
assets/css/style.css
assets/js/main.js
assets/img/        portrait and workshop/research photos
```

Personal details such as phone number, date of birth and home address are intentionally not published.
